# Week 7 — x402 & Farcaster: Pay and Speak

For six weeks the agent learned to **earn**. Week 7 adds the last two verbs: to **pay**, and to **speak**. An agent that only trades is a tool; one that earns, pays, and speaks is an **economic actor**.
