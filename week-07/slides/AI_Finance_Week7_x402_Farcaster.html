Part A · x402 · pay

Money inside the request

HTTP 402 Payment Required — dormant for 20 years, revived by Coinbase. An agent pays USDC on Base, per call.
No account, no card, no human. The payment rides the API request itself.
One handshake

How a paid call flows

GET /data → 402 (price + payTo)
→ sign a USDC payment
→ retry with the payment
→ 200 + the data
The server states a price; the agent decides whether it's worth it, pays, and gets the data — in one round trip.

You don't just consume paid APIs — you sell one. Package data, slap x402 on it, and any agent can pay to call it.
Why it matters

Pay-per-call is the agent economy's plumbing

An agent that can pay can buy data, tools, compute, and services — autonomously, with no human at the till.
This is the lane Coinbase is building. x402 is their protocol; Base is their chain.
The fence · an agent with a wallet that pays

Bound what it can spend

  • a cap per call and a cap per day
  • a payTo allowlist — only known sellers
  • a price sanity check — refuse a server that over-charges
  • testnet / tiny amounts — the key never in the LLM
A malicious server just... asks for more. The fence is what stops the agent from paying it.
Part B · Farcaster · speak

The agent gets a voice

On-chain social: your agent has its own identity and posts — in public — what it did today.
Trading in silence is a script. Reporting its own work in the open is an actor you can watch.
Jarvis posts its day

Build in public, behind a fence

the day's ledger → draft a cast
→ preview (nothing sent)
→ you approve / --yes
→ posted
Every post waits for a human. The draft is sanitized — the strategy and result, never a wallet address or a key.
Why speak

A visible actor earns trust

Reputation · discovery · accountability. An agent that tells you — and the world — what it did is one you can actually hand the keys to.
This is also how you get found: build in public, and the right people read it.
