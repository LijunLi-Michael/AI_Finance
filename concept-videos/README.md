# AI Finance · Concept Videos

Short, animated **explainer videos** on **quant and financial engineering** — the basics of **futures and options**, plus frontier topics like **perpetuals (perps)** and **prediction markets**. This is an **experiment** in teaching these ideas on video: a selected set of explainers, **not full coverage of the course**. Watch them as many times as you need — there's no separate problem set for this unit.

## Order (the storyline)

**① Quant — what you can do on a CEX (e.g. OKX)**
1. **Common Quant Strategies** — what are you betting on? four buckets: direction / spread / flow / sizing.
2. **Quant Metrics 101** — how to judge a strategy: drawdown, Sharpe, Calmar (from a real backtest).
3. **What is Cash-and-Carry** — futures must converge, so you lock the basis; up, down or flat, always the same profit.
4. **What is a Perpetual** — spot plus a funding "spring"; never expires, still leveraged.

**② On-chain**
5. **What is Hyperliquid** — the whole perpetual exchange, on-chain: CEX speed + DEX transparency.

**③ A new on-chain game**
6. **What is Polymarket** — same matching engine, new game: price *is* probability.

**Foundations · overview · the map**
- **Futures & Options Basics** — futures vs options; futures come in two kinds; the call/put × long/short quadrants; binary options.
- **Obligation or Right** — one question sorts every derivative: an obligation is a straight line, a right bends into a kink.
- **Three Anchors** — what pins a contract's price to reality: delivery, funding, or an oracle.
